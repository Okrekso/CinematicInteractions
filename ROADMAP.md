# 🗺️ Roadmap

**[Open the interactive checklist →](https://github.com/dcvke/CinematicInteractions/issues/1)**

The pinned roadmap issue tracks released features, further testing, and ideas under consideration. Checked items are available in published builds. Unchecked feature ideas have no fixed release dates.

The maintainer can tick items directly in the issue and use **Edit** to add tasks or change priorities. Progress is tracked there so the README and Wiki always point to the same list.

Have a suggestion? [Open a feature request](https://github.com/dcvke/CinematicInteractions/issues/new?template=feature_request.yml).
