# 🗺️ Roadmap & progress

**[Open the interactive roadmap checklist →](https://github.com/dcvke/CinematicInteractions/issues/1)**

The roadmap is pinned in the repository's Issues tab. It is the main place to follow progress and update completion status.

## 📋 What the sections mean

| Section | Meaning |
| --- | --- |
| Available now | Checked features are available in published builds. |
| Testing & polish to explore | Open verification work and opportunities to improve compatibility. |
| Feature ideas under consideration | Possible additions, with no fixed release dates or guaranteed implementation. |

## 📝 Updating the checklist

1. Open the roadmap issue while signed in as the repository owner or a collaborator with permission to edit it.
2. Click a checkbox to mark an item complete or reopen it.
3. Use the issue description's **Edit** action to add tasks, reorganize sections, or link related issues and pull requests.
4. Mark a feature complete when it becomes available in a published build, and link the release when possible.

The checklist lives in the issue; this guide and the README link to it so there are no separate copies of progress to maintain.

## 💡 Suggesting something new

Check the roadmap and existing issues, then [open a feature request](https://github.com/dcvke/CinematicInteractions/issues/new?template=feature_request.yml). Explain the interaction you would like and how it would help players. English and Russian are welcome.
