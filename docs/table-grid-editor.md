# Редактор сетки верстака

Первая реализация — **NeoForge 1.21.1, версия мода 0.12.0**. Fabric пока остаётся без редактора по просьбе владельца.

![Редактор сетки в игре с Complementary Reimagined](artwork/table-grid-editor.png)

## Как пользоваться

1. Открой сцену верстака.
2. В настройках мода включи **«Разработчик → Режим разработчика»** (с версии 0.13.0 он по умолчанию выключен).
   Нажми голубой значок из девяти квадратиков справа или клавишу **G** (когда поиск рецепта не в фокусе).
3. Перетащи сетку на столешнице или настрой её ползунками. Колесо над строкой настройки меняет её маленькими шагами.
4. Нажми **«Сохранить» / Enter**. **«Отмена» / Esc** возвращает сохранённую раскладку, оставляя игрока у верстака.

Панель появляется плавно; предметы и рамки плавно переходят к новым позициям. Цифры 1–9 показывают порядок
рецепта со стороны игрока. На время настройки справочник и инвентарь скрыты, клики не перемещают ингредиенты,
клавиши движения не прерывают редактор. Получение урона и другие обычные причины выхода всё ещё завершают сцену:
несохранённые изменения отменяются.

## Настройки

| Параметр | Значение |
| --- | --- |
| Смещение X / Z | Положение сетки по осям текстуры, в пикселях ванильной текстуры; шаг ползунка и колеса — 1/8 пикселя. |
| Поворот | От −180° до +180°. Предметы и области кликов поворачиваются вместе с сеткой. |
| Ширина / глубина | 50–170% от ванильной сетки: меняется расстояние между столбцами / рядами. При повороте большая сетка автоматически ограничивается краями блока. |
| Высота | От −2 до +2 пикселей относительно верха ванильного верстака, для изменённой модели столешницы. |
| Размер вещей | 50–150%: предметы на столе, в руке сцены, во время раскладки и прозрачные ингредиенты справочника. |

Геометрия ограничивается столешницей; для некоторых сочетаний поворота и размера допустимый сдвиг меньше.
Размер вещей выбирается отдельно: крупные предметы могут перекрывать соседей, как и в обычной сетке; существующая
плавная прозрачность перекрывающих ингредиентов учитывает новую раскладку.

## Профили и сохранение

Есть три профиля. Стрелки в верхней строке переключают их; черновики сохраняются при переключении внутри открытого
редактора. **«Сохранить»** записывает все три черновика и выбранный профиль. **«Отмена»** отменяет все изменения
текущего открытия. **«Ванильная сетка»** сбрасывает только текущий черновик, после чего его можно сохранить или отменить.

Файл в папке экземпляра игры: **`config/cinematic-table-layouts.json`**. Его можно передать вместе со сборкой
или скопировать в другой экземпляр игры, пока игра закрыта. Профили выбираются вручную; автоматической привязки
к ресурспакам в первой версии нет. Повреждённый файл не мешает запуску: используются ванильные значения,
а причина записывается в журнал. Ошибка сохранения оставляет редактор открытым и показывает сообщение.

## Что меняется и чего пока нет

Настройка локальная и применяется ко всем видимым верстакам этого клиента, включая предметы, положенные другими
игроками. У каждого игрока может быть своя раскладка под его ресурспак. Текстуры и модели самого ресурспака не меняются.

Серверу по-прежнему отправляются исходные номера ячеек; формат пакетов, ориентация рецептов, хранение предметов,
крафт и обычный GUI остаются прежними. Одна раскладка используется для рендера, кликов, подсветки, прозрачности,
полёта ингредиентов, целей рук и справочника рецептов.

Редактор рассчитан на горизонтальную прямоугольную сетку. Наклон всей столешницы, произвольные формы ячеек,
отдельные смещения каждой клетки, авторские траектории камеры и редакторы других станций в эту версию не входят.
Радикально переделанная 3D-модель может потребовать отдельной адаптации сцены.

## Проверка для разработчика

`./gradlew runShowcase -Pfrom=d -Ponly=true` — отдельный акт редактора. Он также включён в полный акт верстака `0`.
Есть независимая проверка поворота на 90°, ограничений некорректных значений, реальные клики по панели и всем
повёрнутым ячейкам, перетаскивание, масштаб GUI 3, блокировка кликов с предметом в руке, отмена, сброс, переключение
профилей, сохранение JSON и раскладка рецепта в изменённые клетки. В конце восстанавливаются исходные профили и
ингредиенты. Перед запуском стандартно требуется свежий тестовый мир; результаты — журнал и кадры `showcase_0d*.png`.

`TableGrid` остаётся общей логической сеткой; клиентскую геометрию задаёт `TableLayout`, сохранение — `TableLayouts`,
панель — `TableGridEditor`. Файл загружается один раз; дисковые операции происходят только при загрузке / сохранении.
Интерполяция выполняется один раз за кадр в `Scene.frame`, включая кадры вне сцен, поэтому отмена плавно
возвращает прежний вид и после выхода из сцены.
