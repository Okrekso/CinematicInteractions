# Cinematic Interactions — Fabric

**Current beta:** 0.18.28 for Minecraft 1.21.11 and 26.1.1, 26.1.2, 26.2 and 26.3. Download the matching JAR from [GitHub Releases](https://github.com/dcvke/CinematicInteractions/releases). The Fabric 1.21.1 project is in [`1.21.1/`](1.21.1/). Natural Reach arms may render incorrectly; use Stretched or Floating Hands if affected. The information below describes earlier builds and is retained for historical reference.

Актуальная сборка 0.18.2 со всеми редакторами, исправлением Punchy и эффектами инвентаря доступна в отдельных проектах
для [Minecraft 26.2](26.2/README.md) и [Minecraft 26.3](26.3/README.md).
Для Fabric **1.21.11** версия **0.18.3** добавляет совместимость с Inventory Particles и Inventory Interactions
поверх редакторов всех станций, режима разработчика и профилей из 0.18.2.
Включите «Режим разработчика» в настройках и нажмите G или шестерёнку справа во время сцены.
Подробнее — [редакторы 1.21.11](docs/editor-1.21.11.md). Ниже описана общая сборка портов 1.21–1.21.11.
Новая совместимость и её проверка — [эффекты инвентаря в 1.21.11](docs/inventory-effects-1.21.11.md).

Fabric-порт Cinematic Interactions для Minecraft **1.21 – 1.21.11** (1.21, 1.21.1, 1.21.2, 1.21.3, 1.21.4, 1.21.5,
1.21.6, 1.21.7, 1.21.8, 1.21.9, 1.21.10, 1.21.11).
Для каждой версии игры собирается отдельный JAR. Исходный проект NeoForge в родительской папке сохраняется отдельно.

## Установка

1. Установите Fabric Loader **0.16.14 или новее** (для 1.21.9–1.21.11 — **0.17.3 или новее**) для нужной версии Minecraft.
2. Установите Fabric API для той же версии игры.
3. Поместите подходящий `Cinematic Interaction-Fabric-<Minecraft>-<версия мода>.jar` в `mods`.
4. Для полного режима на сервере установите **этот же JAR и Fabric API**. В Fabric 1.21.11 доступен пробный клиентский режим без серверного мода.

Готовые сборки находятся в `../release/fabric/`. Одновременно устанавливается только одна сборка Cinematic Interactions.
Для 1.21.11 версия **0.18.3** содержит редакторы, совместимость с эффектами инвентаря и исправление Punchy из **0.12.4**.
В новой пробной сборке 1.21.11 переключатель клиентского режима находится в разделе «Сетевая игра»
и меняется только из главного меню. На сервере без мода 11 станций показывают локальную сцену
поверх настоящего ванильного меню; на сервере с модом остаётся полный режим. Игрок не перемещается,
камера ограничена 0,35 блока. Остальные станции без серверного мода остаются ванильными.
Сборка 0.18.4: `build/1.21.11/previews/CinematicInteraction-0.18.4-Fabric-1.21.11-client-only.jar`.
Опубликованные сборки не заменены.
Порт 1.21.10 сохранён как **0.12.3**, прежние сборки 1.21–1.21.9 — как **0.12.2**.
При использовании Punchy 2.8f нужен Loader **0.18.0+**; игровой прогон выполнен с 0.19.5.
Подробности исправления — в [отчёте](../docs/punchy-compat.md).

Mod Menu и Cloth Config необязательны: Mod Menu добавляет кнопку настроек, Cloth Config — расширенный экран.

`config/cinematic-client.json`. Перенос настроек из NeoForge TOML автоматически не выполняется.

Сохранены станции, анимации рук и камеры, видимые другим игрокам предметы, справочник рецептов с подсказками
на столешнице, переходы между станциями, чтение книг, резная книжная полка, проигрыватель, настройки и переводы.
Сундуки и бочки продолжают использовать обычные окна.

## Сборка

Нужен JDK 21 (Gradle 9.6.0, Fabric Loom 1.17.21 для 1.21.11 и 1.16.3 для остальных целей). Из этой папки в PowerShell:

```powershell
$env:JAVA_HOME = 'C:\Users\evgen\AppData\Local\Programs\Eclipse Adoptium\jdk-21.0.12.8-hotspot'
.\gradlew.bat --project-cache-dir '.gradle/targets/1.21.1' '-Pmc_version=1.21.1' build
```

Результат: `build/1.21.1/libs/`. Для всех двенадцати версий:

```powershell
.\tools\build-all.ps1
```

Только два новых порта:

```powershell
.\tools\build-all.ps1 -Versions '1.21.10','1.21.11'
```

Скрипт собирает версии последовательно, проверяет метаданные и копирует только готовые игровые JAR в
`../release/fabric/`, затем сохраняет SHA-256. Исходники находятся рядом с игровыми JAR в `build/<версия>/libs/`.

## Устройство порта

- `src/main/java/` — Fabric-события, сеть, настройки и базовый код для 1.21/1.21.1.
- `src/1.21.2/java/` — изменения рецептов, ввода и состояний рендера для 1.21.2/1.21.3.
- `src/1.21.4/java/` — новая система моделей предметов и изменившиеся модели блоков для 1.21.4.
- `src/1.21.5/java/` — GPU-текстуры страниц, конвейеры отрисовки, модели состояний блоков, ввод и SavedData Codec для 1.21.5.
- `src/1.21.6/java/` — новый GUI 1.21.6–1.21.8: матрицы 3×2, слои вместо `flush`, флаги ткацкого станка как
  picture-in-picture, страницы книги в собственных GPU-текстурах, `ValueInput`/`ValueOutput`.
- `src/1.21.9/java/` — система отправки моделей (`SubmitNodeCollector`) 1.21.9: собственные хуки кадра мира
  (`LevelRendererMixin`, `FeatureRenderDispatcherMixin`), предметы через `ItemModels`, `AvatarRenderer`, события ввода.
- `src/1.21.10/java/` — основной проход сцены с Iris: теневые проходы не забирают отрисовку рук и предметов.
- `src/1.21.11/java/` — `Camera.setup(Level, …)`, `RenderSetup`, новый `VertexConsumer`, сигнатуры экрана и слоя
  предмета в руке, безопасная смена буферов ткани. Общие переименования `Identifier`, `RenderTypes`, gamerules,
  регистрация SavedData и сэмплер страниц выполняются в `sourcePatches`.
- `src/*/resources/` — Fabric-метаданные, mixins, access wideners и определение модели молотка для 1.21.5.
- `../src/main/resources/` — общие оригинальные текстуры, переводы, модель молотка и иконка; метаданные NeoForge исключены.

Gradle выбирает последний подходящий вариант каждого Java-файла и собирает исходники в
`build/<версия>/generated/java/`. Эти сгенерированные файлы редактировать не нужно.
Переименования, затронувшие весь код (например, `.serverLevel()` → `.level()` или события ввода 1.21.9),
делаются построчными заменами `sourcePatches` в `build.gradle` при сборке исходников, а не копиями файлов.

Fabric API заменяет события NeoForge и регистрацию сетевых пакетов. Mixins подключают камеру, ввод, скрытие HUD,
позы игроков, синхронизацию чанков и события зачарования. На 1.21.2+ рецепты верстака дополнительно синхронизируются
с сервера, поскольку клиент больше не получает полный прежний список рецептов.

## Проверка в игре

```powershell
.\tools\showcase.ps1 -Version '1.21.4'
.\tools\showcase.ps1 -Version '1.21.5' -From 'k' -Only
.\tools\showcase.ps1 -Version '1.21.5' -From 'o' -Only -WithSettings
.\tools\showcase.ps1 -Version '1.21.5' -From 'k' -Only -WithShaders
.\tools\showcase.ps1 -Version '1.21.10' -WithShaders -WithSettings
.\tools\showcase.ps1 -Version '1.21.11' -WithSettings
```

Для пробного клиентского режима 1.21.11: `./gradlew.bat -Pmc_version=1.21.11 runClientOnlySmoke`.
Он подключается к отдельному чистому серверу на `127.0.0.1:25587`. Нужны верстак `(0,64,1)`,
печь фасадом на север `(1,64,1)`, наковальня фасадом на север `(-1,64,0)`, стол зачарования
`(1,64,-1)` и бревно дуба в первом слоте игрока. Успех отмечается `[ClientOnlySmoke] PASS`.

Каждый прогон использует новый отдельный тестовый мир в `run/<версия>/showcase/`.
Скриншоты сохраняются в его `screenshots/`, журнал — в `build/showcase-<версия>-<акт>.log`.
Скрипт проверяет не только завершение игры, но и строки `check FAILED`.
Акты: `0` — верстак, `3/4/5` — печи, `6` — зачарование, `a` — наковальня, `g` — точило,
`s` — кузнечный стол, `c` — камнерез, `l` — ткацкий станок, `m` — картография, `b` — зельеварка,
`r` — сборщик, `f/u` — костры, `k` — кафедра, `e` — книжная полка, `n` — маяк,
`h` — доступность и падение, `o` — настройки, `t` — переходы, `y` — раскладка рецепта,
`v` — свободный обзор, `j` — проигрыватель, `q` — быстрый возврат, `w` — вид со стороны.

Для параллельных прогонов разных версий скрипт разделяет кеш Gradle по версиям. Не запускайте два прогона
одной версии одновременно: они используют одни выходные файлы и папку скриншотов. Во время клиента нельзя
также собирать или запускать сервер той же версии, даже с отдельным кешем Gradle: папка классов остаётся общей.
Проверки с шейдерами и сторонними модпаками требуют отдельных прогонов с соответствующими Fabric-модами.
Для 1.21.10/1.21.11 `-WithShaders` загружает зафиксированные совместимые Iris и Sodium из Maven;
дополнительные библиотеки этих модов находятся в `test-mods/<версия>/`. Для остальных версий положите
совместимые Fabric Iris и Sodium в эту папку самостоятельно. Шейдерпак поместите в
`run/<версия>/showcase-iris/shaderpacks/`, включите его в `run/<версия>/showcase-iris/config/iris.properties`.
Этот режим использует отдельную папку игры и разрешение 1280×720. Тестовые зависимости в выпускаемые JAR не входят.

Выполненные проверки и их ограничения описаны в [TESTING.md](TESTING.md).
