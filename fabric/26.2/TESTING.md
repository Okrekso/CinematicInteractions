# Fabric 26.2 — проверка порта 0.18.1

Дата: 16 октября 2026. Основа — текущий Fabric 26.3 / 0.18.1 с функциями NeoForge,
включая все редакторы станций, профили, режим разработчика, справочник рецептов,
шкалы костра, переходы и быстрый возврат. Перенесено 153 Java-файла; состав классов
совпадает с 26.3. Изменения API и рендера отделены в `build/port-26.2/source-diff.patch`.

## Среда

- Minecraft 26.2, Java 25, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2.
- Punchy 2.8f (Modrinth O6KuUYUk).
- Cloth Config 26.2.155, Mod Menu 20.0.3.
- Iris 1.11.4, Sodium 0.9.2, Complementary Reimagined r5.9.3.
- Windows, NVIDIA GeForce RTX 4060 Laptop GPU, OpenGL; окно 1600×900.

Проверки идут в отдельных новых мирах Showcase. Пользовательская сборка и сервер
не изменялись. Все сторонние моды подключены только как зависимости локального запуска.

## Проверенные сценарии

Обычный полный прогон с Punchy и экраном Cloth: **747 успешных проверок, 0 провалов**.
Проверены все станции и редакторы, реальные операции с предметами, профили, блокировка
редакторов без dev mode, рецепты, печи, чары, ковка, зелья, костры, книги и маяк.
Также проверены положения блоков на разной высоте, переходы между станциями, обзор
камерой, быстрый возврат, настройки и анимации наблюдаемого игрока.

Шейдерный прогон с Punchy проверяет те же станции и редакторы. Первый запуск дошёл
до конца резной книжной полки: **580 успешных проверок, 0 провалов**; затем запуск
прервался без итогового отчёта. Оставшаяся часть выполнена отдельным запуском от
маяка, включая проверки высоты, настроек и режимов камеры: **165 успешных проверок,
0 провалов**, штатное завершение. Итого с Iris — **745 проверок без провалов**.
Две проверки ванильного поведения полки с выключенной сценой из обычного прогона
не повторялись с Iris. Частичный запуск не выдаётся за завершённый полный прогон.

Отдельный запуск без Punchy, Iris, Cloth Config и Mod Menu: **39 успешных проверок,
0 провалов**. Встроенный экран открывается, dev mode по умолчанию выключен,
все 18 типов профилей переключаются и восстанавливаются.

## Визуальная проверка и Punchy

Просмотрены игровые кадры обычного клиента и Iris: верстак и прозрачность блока,
блеск предметов, зачарование и лазурит, молот на наковальне, узор флага, зелья,
костёр и текст с изгибом страницы книги. Контактные листы:
`build/port-26.2/ordinary-stations.png` и `build/port-26.2/iris-stations.png`.

Проверен фактически преобразованный код `ItemInHandRenderer` в обычном клиенте и
с Iris: весь проход рук и ранние обработчики Punchy находятся внутри `WrapMethod`.
Во время сцены исходный проход пропускается. `@Pseudo`-mixin отключает применение
сохранённого наклона камеры Punchy только пока активна сцена; конфиг Punchy не меняется.
В просмотренных кадрах лишняя рука не перекрывает сцену; после выхода обычная рука возвращается.

## Сервер и состав выпуска

Изолированный выделенный сервер 26.2 с Fabric API и Cinematic успешно дошёл до `Done`,
выполнил `list`, `save-all flush` и штатный `stop`, сохранил мир и завершился с кодом 0.
Журнал: `build/port-26.2/server-success.log`. Сервер привязан к 127.0.0.1:25586.
Cloth, Mod Menu, Iris и Punchy на сервере отсутствовали.

Финальная сборка без тестовых зависимостей: `gradlew build` завершилась успешно.
Проверены CRC архива, метаданные 26.2 / 0.18.1 / Southware, Java 25, наличие всех
153 исходных классов и 255 скомпилированных классов с вложенными, регистрация mixin,
переводы, модель и текстура молотка. Сторонние моды, классы Minecraft, исходники
игры и NeoForge-метаданные в JAR не включены. Все 15 прежних Fabric JAR сверены
по SHA-256 и не изменились. Машинный отчёт: `build/port-26.2/release-audit.json`.

Выпуск: `release/fabric/26.2/Cinematic Interaction-Fabric-26.2-0.18.1.jar` (1 053 642 байта).
SHA-256: `fd293c6ad595bcbebf2bead19b68efbeb2ecdbcc9fd5dd0c492b352e339a6b07`.

## Ограничения проверки

Проверка сервера подтверждает загрузку, сохранение и остановку. Подключение двух
настоящих клиентов к выделенному серверу отдельно не проверялось; позы наблюдателя
проверяются сценарием Showcase. Произвольные ресурспаки, другие версии Punchy,
другие наборы шейдеров и Vulkan этим прогоном не подтверждаются.

Журналы находятся в `build/port-26.2/`, исходные кадры — в
`fabric/26.2/run/showcase/screenshots/` и `fabric/26.2/run/showcase-iris/screenshots/`.
Считаются только исходные строки `[Showcase] check passed`, без повторов `report check passed`.
