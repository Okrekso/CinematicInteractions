# Cinematic Interactions — Fabric 26.1.2

Порт версии **0.18.28** для Minecraft **26.1.2**. Включает актуальные функции Fabric 1.21.1: три режима рук, три режима быстрого возвращения, улучшенные сцены крафта и костра, интеграции JEI и Polymorph, а также исправления зачарования и печей с шейдерами. Рендер сцены адаптирован к API 26.1.2.

## Установка

Нужны Java 25, Fabric Loader 0.19.5 или новее и Fabric API 0.155.3+26.1.2. Установите только один JAR Cinematic Interactions, соответствующий версии Minecraft.

Для полного режима установите мод и Fabric API на клиент и сервер. Клиентский режим позволяет использовать поддерживаемые сцены на обычном сервере без установки мода туда: включите переключатель «Клиентский режим» в настройках из главного меню и подключитесь заново. Этот режим использует настоящие ванильные меню и не перемещает персонажа на сервере. Подробности: [документация](../../docs/client-only-preview.md).

Mod Menu и Cloth Config необязательны. Без Cloth Config доступен встроенный экран настроек. Локальные профили редактора лежат в `config/cinematic-*-layouts.json` и совместимы с другими актуальными сборками.

## Сборка и проверка

```powershell
$env:JAVA_HOME = 'путь к JDK 25'
.\gradlew.bat build
.\gradlew.bat runShowcase -Pfrom=0 -Ponly=true
.\gradlew.bat runShowcase -PwithPunchy -PwithInventoryEffects -PwithSettings
```

`runClientOnlySmoke` проверяет клиентский режим при запущенном отдельно ванильном сервере на `127.0.0.1:25587` с подготовленным тестовым миром. Его сценарий находится в `ClientOnlySmoke.java`.

Исходники этого порта находятся только в этой папке; прежние версии и выпуски не изменены.
