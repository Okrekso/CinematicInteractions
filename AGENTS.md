# Contributor guide for automated assistants

Read README.md, CONTRIBUTING.md, docs/wiki/Development.md, and CREDITS.md before changing the project.

- This repository contains NeoForge 1.21.1 at the root and Fabric 1.21–1.21.11 in fabric/.
- NeoForge behavior is the visual and gameplay reference. Keep all affected Fabric overlays consistent when changing shared behavior.
- Fabric uses the latest matching file from src/main, src/1.21.2, src/1.21.4, src/1.21.5, src/1.21.6, src/1.21.9, src/1.21.10, and src/1.21.11; small API substitutions are in fabric/build.gradle.
- Shared resources are in root src/main/resources. Do not edit generated sources under build/.
- Java 21; use the checked-in wrappers. Do not update game, loader, or build tool versions without an explicit request.
- Preserve smooth camera transitions, skin-aware hands, station timing, picking geometry, and multiplayer synchronization.
- Keep both English and Russian translations current. Add English comments that explain the reason for a non-obvious choice.
- Build affected targets. Rendering and animation changes also require the relevant Showcase acts and visual inspection; consult fabric/TESTING.md for coverage and limits.
- Do not compile or launch a server for a version while that version's Showcase client is running: they share class output.
- Never commit local game profiles, worlds, downloaded dependencies, credentials, screenshots generated by a run, or decompiled game references.
- Do not install a build into a player's instance or server or publish a release unless explicitly requested.
- Preserve third-party attribution, especially the CC BY 4.0 hammer model in CREDITS.md.
